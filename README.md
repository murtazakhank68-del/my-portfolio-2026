
# ⚡ SmartTask – Project Management Dashboard

A modern and responsive task management application built using HTML, CSS, and Vanilla JavaScript.

## 🚀 Features

- Professional dashboard
- Create, edit and delete tasks
- Search and filter tasks
- Task priority management
- Drag and drop Kanban board
- Real-time task statistics
- Productivity analytics
- Dark and light mode
- LocalStorage data persistence
- Responsive mobile-friendly design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Browser LocalStorage

## 📂 Project Structure

SmartTask/
├── index.html
├── style.css
└── script.js

## 💻 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open index.html in your browser.
4. Start managing your tasks!

## 🎯 Project Purpose

This project demonstrates frontend web development skills, DOM manipulation, CRUD operations, event handling, and responsive UI design.
